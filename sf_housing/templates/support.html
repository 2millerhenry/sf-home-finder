Your data

Everything this app knows is one file on this computer, {{ database_name }}. It has never been anywhere else, and uninstalling leaves it where it is unless you type DELETE when asked.

{{ data_folder }}
Reading it yourself

An ordinary SQLite file: any SQLite browser opens it, as do pandas.read_sql and the sqlite3 command. Three tables carry everything worth reading.

  • listings — one row per listing on one site, with its score, price, neighborhood, original_url, and whatever you marked or wrote in status and note. Rows with the same home_key are one home on several sites. status_reason says who moved a row: user for you, aged for the three-week archive. An aged-out row is deleted once it has been in the archive four months and its site, searched since, has not listed it for as long; nothing you starred, noted or passed ever is.
  • scan_runs — one row per check, with what started it and how it ended.
  • source_runs — one row per source within a check, with how many homes it saw.
SELECT price, neighborhood, title, original_url
FROM listings
WHERE status = 'saved'
ORDER BY price;

If you copy the database while the app is running, take the -wal and -shm files beside it too, or your copy will open fine and be missing the newest homes. Columns ending _json are this app talking to itself: their shape changes between versions, so build nothing on them. For a shortlist rather than everything, the Shortlist has a Download as CSV button.
